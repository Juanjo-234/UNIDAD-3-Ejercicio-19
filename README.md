Resolución del ejercicio N°19 de la unidad 3 de programación 2.
Este programa encapsula los datos de contacto y protege sus atributos mediante validaciones estrictas en los métodos modificadores, garantizando que solo se acepten números de teléfono sin letras y correos electrónicos con formato válido, y exponiendo de manera segura una representación formateada de la información.
